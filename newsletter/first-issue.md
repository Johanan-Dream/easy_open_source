# 파일은 가볍게 보내고, AI는 내 컴퓨터에서.

안녕하세요. Easy Open Source입니다.

이번 주에는 복잡한 가입 없이 바로 시작할 수 있는 도구들이 눈에 띄었어요. 그중에서도 처음 설치하는 사람에게 부담이 적고, 일상에서 바로 써볼 만한 세 가지를 골랐습니다.

## 01 · LocalSend

**파일 전송 · 설치 난이도 쉬움**

사진 한 장 보내려고 메신저에 로그인하거나 클라우드에 올릴 필요가 없어요. 같은 와이파이에 연결된 기기끼리 파일을 바로 주고받는 도구입니다.

- 이럴 때 좋아요: 휴대폰 사진을 PC로 옮길 때
- 사용 환경: Windows · macOS · 모바일
- 예상 설치 시간: 약 5분
- 비용: 무료 · 계정 필요 없음

터미널 명령어나 별도 설정 없이 설치 프로그램만 실행하면 돼요. 오픈소스를 처음 접하는 사람도 결과를 바로 체감할 수 있습니다.

[LocalSend 사용법 보기](https://wv1787506230054545.zaemit.ai/#explore)
